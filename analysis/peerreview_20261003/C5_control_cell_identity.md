# C5 — Control-cell identity check (GSE216146, fresh full-model latents)

Script: `scripts/28_c5_control_identity.py` (log `runs/peerreview_20261003/logs/28_c5.log`). Latents:
`runs/peerreview_20261003/canonical/full_{0,1,2}_latents.npz` (ungated posterior means `raw_shared`, `raw_drug`).

## Method

- Cells: GSE216146 nonrescue cells; control = PBS (source code PN), cisplatin = CN.
- Probe: `LogisticRegression(max_iter=800, class_weight='balanced')` (as in `11_diagnostics.py`) predicting
  `source_cell_type` (12 classes present in both training and test cells of each arm), trained on the canonical
  training cells of that arm and scored by balanced accuracy on the canonical test cells of that arm.
  Chance level = 1/12 = 0.083.
- Blocks: ungated shared posterior means (8 dims); ungated cisplatin-specific drug head (`raw_drug[:, 4:8]`,
  4 dims); full ungated drug block (`raw_drug`, 8 dims: doxorubicin and cisplatin heads).
- Block norm: Euclidean norm of the ungated posterior-mean vector; mean and SD (ddof = 1) per source cell type over
  all nonrescue cells of each arm. Test-cell-only values: `C5_block_norms_by_celltype.csv` (`scope = test_cells`).
  Cell counts per arm/split/cell type: `C5_cell_counts.csv`.

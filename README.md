# Chemotherapy transcriptome representation research

The current corrected analysis is `corrected_20260920`. This repository contains the research implementation, corrected preprocessing, benchmark scripts, compact numerical results, training histories and data-download instructions. Raw data, processed matrices, fitted checkpoints and large intermediates are intentionally excluded. Manuscript sources and publication figures are maintained separately.

## Corrected analysis

An audit identified reversed cisplatin labels and rescue arms pooled with the original training conditions. In GSE216146, PN/PS are PBS and CN/CS are cisplatin. PS/CS are GENUS rescue arms. The corrected workflow excludes rescue from fitting. Historical runs remain unchanged for provenance and must not be interpreted as corrected results.

Both studies sample mouse hippocampus. GSE216146 contains whole cells and GSE271055 contains nuclei. Drug identity is confounded with study and modality. Doxorubicin has one pooled library per arm, so its contributing mice do not provide independent expression replicates.

The recovered cohort contains 46,857 observations across 15 libraries. The benchmark uses 6,000 training observations, 2,881 validation observations, 2,881 test observations and 1,500 training-selected genes. Splits are at the cell level within deposited libraries.

| PCA with 32 components | One fit | 0.1552 |

These comparisons do not establish reconstruction superiority for MC-ContrastiveVI. A pinned external scDisInFact comparison on the same canonical split likewise did not resolve the design problem: scDisInFact had mean held-out log-expression MSE 0.2313 versus 0.1687 for the archived MC checkpoints and 0.1552 for PCA, while its shared-bio and unshared-bio factors remained highly predictive of study (balanced accuracy 0.895 and 0.981). Unlike the MC salient spaces, however, scDisInFact latents were much more stable across seeds (mean linear CKA 0.815 shared-bio and 0.842 unshared-bio), and condition-associated gene-score rankings had pairwise Spearman 0.843-0.882. This comparison is descriptive because the methods assign different semantics to their latent blocks and drug remains partially aliased with study. A separate leave-one-GEO-replicate-pair-out validation withheld entire GSE216146 control/cisplatin library pairs from training, validation and feature selection. Across three folds, full MC-ContrastiveVI had mean seen-library balanced MSE 0.0910 and unseen-library balanced MSE 0.0940 (mean ratio 1.035), indicating only a modest reconstruction penalty outside the fitted libraries. PCA(32) remained better in every fold, with mean unseen-library MSE 0.0860, and the noncontrastive Gaussian VAE was also slightly better at 0.0926. This sensitivity analysis therefore supports transfer of basic reconstruction to unseen deposited libraries but not a reconstruction advantage for the contrastive architecture. The three archived full Gaussian checkpoints have shared posterior-mean variance fractions of 92.1%–95.7%, but a latent-utilization audit found 0, 0 and 1 of 8 active shared dimensions across seeds using `Var_x[E_q(z_j|x)] > 0.01`, no active doxorubicin- or cisplatin-specific dimensions, and no salient coordinate with mean KL > 0.01 nats. Across nine fresh CPU reruns, the pooled shared fraction ranged from 75.0% to 98.1% while held-out MSE remained 0.1685–0.1688. A separate exact library-label exchangeability analysis used a label-independent balanced benchmark and the 16 assignments that preserve the three GEO-defined cisplatin-study replicate pairs plus the two-way pooled doxorubicin-study exchange. The observed labels had mean `F_sh=0.7762` across seeds; 12/16 assignments were at least as large (`P=0.750`, reference median `0.8876`). Thus the observed labels did not yield an unusually large shared fraction under this model-specific reference. The shared fraction is an execution- and allocation-sensitive coordinate statistic; it is not a percentage of toxicity or stable evidence of cross-drug biology. A separate rescue audit corrected the cisplatin GENUS sensitivity reference to the three GEO replicate pairs: the seed-averaged rescue-minus-treatment distance difference was 0.000324 and the exact two-sided 8-assignment sign-flip reference probability was 1.000; the minimum attainable two-sided probability is 0.25. Paired library-level pseudobulk analysis in GSE216146 used PyDESeq2 0.5.4 with `~ replicate + condition` across the three GEO replicate blocks. It reported 297 cisplatin-vs-control, 55 cisplatin+GENUS-vs-cisplatin and 2 control+GENUS-vs-control gene-by-cell-type discoveries at adjusted P<0.05. Of 354 total discoveries, 353 had the same effect direction in all three replicate pairs. However, with only three pairs the exact two-sided sign-flip sensitivity has a minimum attainable P=0.25, and the historical unpaired Welch sensitivity yielded only one FDR<0.05 discovery. These are therefore model-based exploratory differential-expression results. ## Reproduce the research

The completed fits used Python 3.12.14 on CPU. Exact package versions are in `requirements-research.txt` and the environment record is in `analysis/corrected_20260920/environment.json`.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-research.txt
pip install -r requirements-task4.txt
make research-analysis
make research-check
```

The analysis target downloads pinned public inputs, corrects labels, performs QC and splitting, fits fifteen neural models plus PCA, and runs annotation, attribution, enrichment, paired library-level pseudobulk and rescue diagnostics. It is computationally expensive and replaces local corrected outputs. Use a fresh checkout to retain published summary tables. The invariant checks require the locally generated arrays and do not run on a summaries-only checkout.

`make research-download` retrieves source matrices, GEO metadata and the exact mouse MSigDB 2025.1 gene-set collections without fitting models. File checksums are supplied in `data/evidence/source_file_manifest.csv`. The full raw and processed datasets, exact model arrays and trained checkpoints are not hosted in GitHub. Large attribution and pseudobulk tables are regenerated by the analysis scripts. The Task 2 exchangeability analysis is intentionally not part of the default `research-analysis` target because a fresh run adds 48 model fits. After data recovery, run `python scripts/15_shared_fraction_null.py --prepare --run` or use the dedicated GitHub Actions workflow.

## Research outputs

`analysis/corrected_20260920` contains cohort and label audits, annotation diagnostics, model comparisons, latent probes, seed stability, latent-utilization and execution-context audits, the exact library-label exchangeability reference, the leave-one-replicate-pair-out unseen-library validation, variance uncertainty, integration completeness, enrichment tests, the paired pseudobulk audit and compact summaries, and the corrected replicate-pair rescue sign-flip analysis. `runs/corrected_20260920` contains per-fit metrics, epoch histories and computational logs. `data/evidence` contains source GEO records and checksums.

The canonical workflow is implemented in scripts 05 through 14 plus `scripts/16_pseudobulk_paired.py` and `scripts/run_research_analysis.sh`; `scripts/15_shared_fraction_null.py` implements the separate 48-fit label-exchangeability sensitivity analysis, and `scripts/17_unseen_library_validation.py` implements the separate 18-fit GSE216146 unseen-library sensitivity analysis, and `scripts/18_scdisinfact_comparison.py` implements the pinned three-seed scDisInFact external-method comparison. The original `src/models/mc_contrastive_vi.py` supplies the Gaussian architecture. Scripts 01 and 02 retain the legacy workflow with corrected labels, rescue handling and unsupported-likelihood safeguards. Legacy Makefile targets remain available, but use `research-*` for the corrected analysis.

The supplied historical checkpoint did not match the designated historical run and lacked its original gene order. `analysis/corrected_20260920/checkpoint_audit.json` records this mismatch. The optional script `07_historical_check.py` requires that separate local checkpoint and is not part of the default reproduction command.
